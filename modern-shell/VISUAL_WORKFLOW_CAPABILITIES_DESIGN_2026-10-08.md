# 可视化流程实用动作 Gate

基线：0eb68d203fb23ff513b67e980cda5ce8e303d68f。用户已确认扩展范围及三列 UI，并授权开始施工；沿用已有交接规则，无需新增 agent 文件。

## 目标与验收

保留已有六种动作，增加获取点击对象/单个选中对象/当前目录/剪贴板、打开终端、解压、设置剪贴板、等待窗口、激活窗口、简单 If / Else。启动程序增加参数和工作目录。通过下拉选择前序结果，不要求填写 AHK 表达式。

三个可直接载入的示例：Explorer/桌面 Alt + 左键，目录打开终端、压缩包解压；Ctrl + Alt + C 复制选中对象路径；Ctrl + Alt + N 启动程序、等待对应窗口、激活并输入。终端沿用已有鼠标上方定位实现；解压沿用 ArchiveExtractionService 的不覆盖与路径保护实现。

## 语言和兼容性

- v1 编解码、生成字节与成对保存的冲突/恢复保护保持兼容；v2 使用独立生成器。只有编辑引入 v2 能力时升级文档，不在打开时自动改写。
- 新参数采用封闭类型：固定值或结果引用（步骤 GUID、字段）。不支持自由表达式。结果字段按动作种类枚举，拒绝前向、已删除、不存在及条件分支之外不可见的引用。
- 最多 24 个动作（含条件和两个分支），条件最多嵌套 3 层。If True/Else 独立顺序；新增动作进入明确选中的分支；根序列和分支都能通过按钮调整顺序。含条件的流程不启用跨分支拖拽。
- 多个选中对象明确报错，不静默选择第一个。点击目标复用 Shell/UIA/MSAA 解析，不用剪贴板模拟，不猜测隐藏扩展名。
- 获取上下文生成路径、父目录、名字、扩展名等结果；剪贴板生成文本；启动程序生成 PID；等待窗口生成 HWND。窗口等待最多 60 秒，超时停止当前流程；激活后输入检查目标仍处于活动状态。
- 每次触发独立结果，鼠标事件保留原生点击，拒绝拖动。运行时失败记录现有诊断日志并显示通知，后续步骤不执行。
- 程序参数可填写固定命令行，或选择一个前序路径/文本结果作为单个参数（自动按 Windows 规则加引号）；工作目录可使用前序目录结果。重定向到另一个 PID 的应用，可改用 executable 名称等待，示例采用该方式。

## UI 与边界

保留填满内容视口的响应式三列布局。左侧折叠分类；中间条件分支缩进并显示明确添加入口；右侧固定值/前序结果选择器、适用字段、超时与程序参数。增加三个示例入口，替换有未保存修改的草稿仍使用现有确认机制。

保存不执行或重启脚本。内置快捷键和同一管理器已运行的可视化流程出现快捷键冲突时，提示并拒绝新运行，用户自行调整快捷键；不会静默关闭原有功能。未知外部 AHK 快捷键不保证检测。

冲突保护同样覆盖启用内置快捷键及修改其设置；完整成对文件之外的普通/手改 AHK 不作准确性保证。v2 引用的 v3 Shell/Actions 资源与生成器作为版本化语义保存，后续核心升级应添加新资源/语言版本而不能悄悄改变既有输出。

解压是显式流程操作，不受“内置快速解压快捷键”开关控制。通过管理器新增 headless 命令复用现有解压服务；生成脚本的终端和 Shell 支持代码引用嵌入资源的原有函数。解压动作依赖本机已安装的 AutoHotkeyUX，缺失时给出明确错误。任意旧 AHK 转译、循环、批量破坏性文件操作仍留到后续阶段。

## 验证与交付

先展示可交互预览，再改产品代码。执行针对 v1 兼容、v2 引用作用域、嵌套编辑、失败路径的最小充分验证；真实 AHK 解析/运行验证生成结果；原生 WinUI 验证分类、引用、分支和宽中窄几何。一次独立最终审阅，修复有实际影响的发现。保留备份、证明、编码记录，合并并部署到正式路径，输出增量源码 ZIP。
