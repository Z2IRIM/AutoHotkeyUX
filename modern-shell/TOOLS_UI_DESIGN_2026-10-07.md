# Home 工具内嵌现代界面设计

状态：用户于 2026-10-07 确认设计、施工方向及交互预览，要求按预览实现。三个真实工具已实现、独立审阅修复、验收并应用到本机单 EXE；详见 `CODING_RECORD_2026-10-07_TOOLS_UI.md`。窗口尺寸、模板间距、移除顶部搜索栏已独立完成、验证并应用。

## 目标与约束

用户要求 Window Spy、Compile、Documentation 与 WinUI 主项目视觉一致，点击 Home 工具卡片后在 APP 内显示，不再启动旧工具窗口。

复用现有 MainWindow 页面承载、Home 入口、主题资源和内置 AutoHotkey v2.0.29。保留单 EXE、私有运行时、静默自启动、托盘及现有脚本所有权逻辑。三个工具属于 Home 的二级页面；侧栏 Home 保持选中，页内提供返回 Home。系统文件/目录选择器属于文件选择交互，继续使用原生选择器。

## 推荐方案

原生 WinUI 工具页 + 小型专用服务。采集使用只读 Windows API；编译调用官方 Ahk2Exe 无界面 CLI；帮助用 WebView2 呈现离线官方 HTML，原生工具栏和主题衔接主项目。

把旧工具窗口强行嵌进主窗口会保留旧外观、焦点和生命周期问题，不符合要求。全部重写编译器和文档内容又会复制官方实现，维护成本过高。因此只重建界面与调用边界。

交互预览：本次对话中的 AutoHotkey 工具页面预览。展示数据与编译输出是示例，不代表已接入实际功能。

## Window Spy

- 展示窗口标题、Class、进程、PID、窗口句柄、屏幕/窗口/客户区鼠标坐标、鼠标位置颜色、控件 ClassNN/文本/区域、窗口与客户区位置。
- 页面提供 Follow mouse、暂停/恢复、复制选择器；按住 Ctrl 或 Shift 可冻结采集，窗口文本/状态栏置于可展开区域。
- 页面可见时约每 250ms 更新；离开页、暂停、窗口隐藏/最小化时停止采集。进入页面只启动一条采集循环，避免反复导航积累定时器。
- 在后台采集，超时读取外部控件文本，防止目标进程无响应拖住 APP。保留最后有效的外部目标，鼠标进入自己的 APP 时避免反复捕获自身。
- 读取失败、受限进程、控件无文本分别显示无数据/不可读取。日志只记录采集错误，不保存用户窗口标题、控件文本或屏幕内容。
- 常规 Win32 控件先保证与旧 Window Spy 同等信息；UIA 深层控件分析不在本阶段扩展。

## Compile

- 选择 .ahk 源文件、输出 .exe、可选 .ico，以及 32/64 位；默认使用内置 v2.0.29 对应架构作为编译基底。
- 当前 runtime ZIP 不包含 Ahk2Exe。本阶段单独嵌入固定版本的官方编译器资源，并核验 SHA-256；独立存放于私有工具缓存，不修改已冻结的运行时下载/解压/发现架构，不要求系统安装 AHK，也不弹安装器。
- 调用官方 CLI 的 silent 模式；显示进度、退出码和可操作错误。一次只运行一个编译任务；重复点击不可重复提交。运行期间允许取消，退出管理器处理自己创建的编译进程。
- 输出先写同目录临时文件，成功后移动至指定路径；失败清理临时文件，不破坏已有产物。默认文件名避免覆盖；确需替换已存在目标时在页内明确确认。
- 不自动运行产物。成功后可打开输出目录。保留脚本中的官方编译指令；明确说明编译可能处理 FileInstall 或脚本中的构建指令。
- 不增加 UPX、MPRESS 或其它可选压缩器依赖。

## Documentation

- 复用内置 v2.0.29 的 AutoHotkey.chm，首次后台提取到应用私有版本缓存，后续复用。提取失败在页内显示错误和重试，不启动 hh.exe 帮助窗口。
- WinUI 工具栏提供返回、前进、目录；离线官方目录和内部链接在页面内工作。正文配色、字体、代码块与主项目主题衔接，保留原始文档语义与链接。
- WebView2 仅映射文档缓存目录，不开放任意本机目录；处理新窗口请求与非文档链接，防止导航到任意 file:// 或启动外部程序。需要访问外部参考资料时明确在页内标识。
- 如 WebView2 运行时不可用，页面显示具体原因与修复入口；不静默安装依赖或退回旧帮助弹窗。

## 模块边界

MainWindow 统一负责页路由与 Home 返回；Home 卡片传递导航意图。三个 Page 负责绑定、状态和消息显示；三个服务负责采集、编译、文档缓存。ApplicationServices 管理共享实例与退出清理。删去不再使用的旧工具 GUI 启动入口，避免维持两套工具流程。

编译器资源与许可证随源码记录；文件路径、PID、句柄作为明确类型数据，不把 UI 文本解析回执行参数。异步返回必须检查页面加载/任务代次，避免过期结果更新已离开的页。

## 最小充分验收

1. 真 WinUI 导航三个工具页与返回 Home，侧栏状态正确，没有新增旧工具窗口或安装器。
2. Window Spy 对真实资源管理器读取窗口/坐标；冻结、恢复、离开页后采集停止，多次导航不重复启动采集。
3. 官方编译器编译一个最小 v2 脚本，检查产物；错误源文件、存在的输出文件、取消分别在页内正确处理。
4. 离线文档首次加载、内部链接与返回；离开/重进页面不产生旧帮助窗口；加载失败可重试。
5. Release 构建、单 EXE 打包、Git 记录、任务 Markdown 记录、增量源码包与回滚文件。

已有快捷键逻辑不改动，不重复已完成的快捷键性能和全面测试。当前任务不再次执行上一任务已完成的关机。

## 风险与待验证边界

第三方/受保护窗口的控件文本不保证可读；复杂脚本编译依赖仍由脚本负责。离线帮助提取和 WebView2 初始化要验证本机真实行为；编译器 silent 错误返回必须用官方固定版本实测。常规 UI 预览不能替代这三项集成验证。

无数据库/API 迁移；新增的私有工具/文档缓存可重建。回滚还原前一版 EXE 和本阶段 Git 文件，用户脚本与设置不回滚。
