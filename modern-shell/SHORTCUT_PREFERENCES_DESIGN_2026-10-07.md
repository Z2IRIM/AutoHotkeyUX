# Explorer shortcuts 配置设计

用户已批准 `autohotkey-shortcut-settings.html` 预览。本阶段一次完成配置、运行时接入、近期动作和交付，不更改已批准的 H 图标或主窗口比例。

- Settings 的二级页：Preferences / Recent activity，导航仍选中 Settings；复用主项目主题、卡片与提示组件。
- 终端和解压独立开关与快捷键。目录/文件区域空白处开启终端，压缩包解压；两个动作允许相同的 Alt + 左键，按目标类型区分。预留组合仅限预览列出的按键，Ctrl + 左键因资源管理器多选而拒绝。
- 终端程序 auto/wt/powershell；位置 above/center；默认 800 × 440 DIP、间距 12 DIP；范围宽 480–1600、高 240–1000、间距 0–64。按显示缩放并限制在点击屏幕工作区内。
- 解压默认在源文件旁建目录，也可指定已有绝对目录；每个压缩包仍建独立子目录，保留源文件和已存在的目录，保留现有路径、链接、大小和校验保护。
- 编辑只修改草稿；Save changes 统一提交，Discard 回到已保存状态。共享入口串行处理启停/配置，避免重复提交。运行时确认或注册/持久化失败必须可诊断；确认超时不能被错误描述成已回滚或已成功。
- 保持现有 HKCU\\Software\\AutoHotkey\\Modern 合约。新增一个完整的 ShortcutPreferences REG_SZ 值，使用有 schema/revision 的有界键值协议；整组设置一次写入。v3 脚本缓存配置，通过消息接收更新，不持续轮询。
- 运行中的 v3 脚本负责校验、注册热键、原子持久化和更新缓存，失败恢复旧热键与缓存。消息带一次性令牌并验证受管进程身份；重复 revision 幂等。超时读回与状态确认；无法确认则明确报告不确定状态，避免盲目重试或重复动作。
- 仅升级经哈希确认未编辑的 v1/v2 根脚本与模块。施工前及自动升级前备份；用户改过的脚本/模块保留并明确说明配置不兼容。v2 模块保持原样，新增版本化 v3 模块。
- 最近动作只保存本次管理器会话最近 50 条，含终端/解压结果、路径、耗时、输出或错误；事件驱动更新，不另建数据库或日志轮询。
- 继续复用现有 ScriptExecutionService、ScriptStartupService、ShortcutCommandService 和 ArchiveExtractionService；排队时冻结解压目标配置，修改设置不会改变已接受的任务。
- 同阶段修复 Window Spy 在控件枚举上限之外错误生成 ClassNN：不能确认序号时显示 unavailable，不猜测。
- 另附 Markdown 脚本创建指南和独立 v2 示例。示例不占用内置 Alt + 左键，不自动安装或运行。

## 验证与交付

按失败成本执行最小充分验证：协议/校验/失败保留/固定目录解压/自定义文件保护/有限历史的源链接检查，真实隔离 AHK 更新和终端定位检查，真实 WinUI 配置页诊断与发布构建。保持用户现有脚本会话；最终部署新管理器，只按已确认的升级条件重启内置脚本。更新编码记录和源码打包脚本，增量源码包同步到 C:\\DESKTOP\\srcpack_Area\\AutoHotkeyUX。
